# 단일 조각 퍼펙트 클리어 분류

폭 w 보드, 빈 보드에서 시작, 한 종류의 테트로미노만 사용해 퍼펙트 클리어가 가능한가?

## 보조정리 0 (열 카운팅)

셀은 열을 바꾸지 않는다. 줄 클리어 1회는 모든 열에서 정확히 1칸씩 제거한다.
퍼펙트 클리어로 끝나면 최종 보드가 비므로, 총 R줄을 클리어했다면

    (열 c에 놓인 총 칸 수) = R    모든 c에 대해

회전 시스템, 킥, 소프트드롭과 무관한 조합론적 항등식이다.
조각 수는 n = R*w/4 이므로 R*w 가 4의 배수여야 한다.

## 열 프로파일

각 조각이 회전에 따라 연속한 열들에 기여하는 칸 수:

    I : (1,1,1,1) / (4)
    O : (2,2)
    T : (1,2,1) / (1,3) / (3,1)
    S : (1,2,1) / (2,2)
    Z : (1,2,1) / (2,2)
    J : (2,1,1) / (1,1,2) / (1,3) / (3,1)
    L : (1,1,2) / (2,1,1) / (3,1) / (1,3)

J 와 L 은 프로파일 집합이 완전히 동일하다. 따라서 열 카운팅은 이 둘을
원리적으로 구별할 수 없다.

**정정 (2026-09-19).** 이 자리에 "실제로 w=4 에서 J 는 n=2, L 은 n=4 로 갈리는데
그 차이는 전적으로 기하에서 나온다" 고 적혀 있었다. **틀렸고, 보조정리 M 과도 모순이다.**
`pc3 4 2 32 0` 과 `pc3 4 2 64 0` 이 둘 다 FOUND 이므로 w=4 최소는 J·L 모두 n=2 다.
기하가 둘을 가르는 일은 없다 — 거울상이므로 가를 수가 없다. 아래 보조정리 M 참조.

가능한 R 의 집합은 덧셈에 닫혀 있다 (두 해를 더하면 해). 즉 수치 반군이므로
최소 원소만 찾으면 된다.

## 정리 1 (S, Z: 모든 폭에서 불가능)

h_c = 시작열 c인 가로 S 개수, v_c = 세로 S 개수.

    col 0 :  h_0 + 2 v_0                  = R
    col 1 :  h_1 + 2 h_0 + 2 v_1 + 2 v_0  = R

차를 취하면  h_1 + h_0 + 2 v_1 = 0.  전부 음이 아니므로 h_0 = h_1 = v_1 = 0.
귀납적으로 col(2k+1) - col(2k) 에서  h_(2k+1) + h_(2k) + 2 v_(2k+1) = 0.

=> 가로 S는 하나도 못 쓴다. 세로 S만, 짝수 열에만, 각각 R/2 개씩.

(a) w 홀수: w-1이 짝수 인덱스인데 v_(w-1)은 열 w를 침범하므로 0.
    따라서 col(w-1) = 0 = R. 모순.

(b) w 짝수: 카운팅은 여기서 막지 못한다 (R=2, n=w/2 에 해가 존재).
    기하가 필요하다. 세로 S 의 모양은

        #.          왼쪽 열 : 상대행 1, 2
        ##          오른쪽 열 : 상대행 0, 1
        .#   <- 상대행 0

    즉 **오른쪽 열만 상대행 0 에 닿는다**.
    세로 S 는 짝수 열 c 에서만 시작하므로, 짝수 열의 셀은 항상 상대행 >= 1 이다.
    특히 열 0 은 짝수 인덱스이므로 어떤 **배치**도 (0,0) 을 채우지 못한다.
    **낙하**로도 못 채운다: 칸이 행 0 까지 내려오려면 자기 아래의 행 0 이 클리어돼야 하고,
    행 0 클리어는 (0,0) 이 차 있어야 한다. 순환이므로 두 명제를 동시 귀납으로 본다
    (2026-09-15 감사에서 이 단계가 빠져 있어 보강).
    => (0,0) 은 영원히 비고, 행 0 은 절대 꽉 차지 않아 절대 클리어되지 않는다.
    첫 조각은 빈 보드에서 바닥에 닿으므로 행 0 에 칸을 하나 남기고
    (세로 S 를 열 c 에 놓으면 (0, c+1)), 그 칸은 영원히 제거 불가. 모순.

    Z 는 거울상이라 세로 Z 의 왼쪽 열이 상대행 0 에 닿고, 막히는 것은 홀수 열이다.
    열 w-1 이 홀수 인덱스이므로 (0, w-1) 이 영원히 비고, 같은 결론.

(Z 의 경우는 위 (b) 마지막 문단. 거울 대칭이므로 (a) 도 동일.)   [QED]

주: 회전 시스템 비의존. 사용한 가정은
    (1) S의 열 프로파일은 (1,2,1) 또는 (2,2)
    (2) 조각은 받쳐진 상태로만 고정 — 빈 보드의 첫 조각은 바닥에 닿음
SRS, 킥, S-스핀, 무한 소프트드롭 모두 뚫지 못한다.

## 정리 2 (O: w 짝수일 때만 가능)

o_c = 시작열 c인 O 개수.
    col 0 : 2 o_0         = R
    col 1 : 2 o_1 + 2 o_0 = R   =>  o_1 = 0
귀납: o_(홀수) = 0, o_(짝수) = R/2.
w 홀수면 o_(w-1) = 0 (범위 밖)이고 w-2는 홀수 인덱스라 0 => R = 0. 모순.
w 짝수면 (0,1),(2,3),... 에 O를 한 층 깔면 2줄 클리어. 가능.      [QED]

## 정리 3 (I, T: 모든 폭에서 가능)

### 3(a) I

세로 I를 각 열에 하나씩 총 w개. 4줄이 꽉 차고 전부 클리어되어 빈 보드.  [QED]

주: 이 구성은 최소가 아니다. w = 0 (mod 4) 이면 가로 I 를 한 줄에 w/4 개 깔아
    R=1, n=w/4 로 끝난다 (w=4 -> 1, w=8 -> 2). 대조표의 최소값은 이쪽이다.

### 3(b) T — 모든 폭 w >= 4 에서 가능하고 최소 조각 수는 n = w (2026-09-16)

**w >= 4 는 진짜 제약이다 (2026-09-20).** 논문 초고의 부분집합 분류가 폭 제한 없이
"{I,T,J,L} 과 만나면 가능" 이라고 써 있길래 작은 폭을 확인했다.

    T  w=2 (n=2)  NO      w=3 (n=3)  NO      w=1 은 배치 자체가 불가능
    I  w=1.2.3    전부 FOUND
    J  w=2.3      전부 FOUND   (L 은 보조정리 M)

**T 만 작은 폭에서 실패한다.** 열 카운팅은 w=2.3 에서도 R=4 를 허용하므로(2 열이면
p_0 = q_0 = 1 이 해다) 여기도 카운팅이 못 잡고 기하가 잡는 자리다 — S.Z 짝수 폭과 같은 구조.
논문의 부분집합 분류는 w >= 4 로 제한했다.

전문은 `t-widths-ko.md`. 요약만 둔다.

**하한.** T 의 열 프로파일은 가로 (1,2,1), 세로 (1,3), (3,1) 셋뿐이다.
h_c, p_c, q_c 를 각 프로파일의 시작열 c 개수라 하면 열 j 의 칸 수는

    N_j = h_j + 2h_(j-1) + h_(j-2) + p_j + 3p_(j-1) + 3q_j + q_(j-1) = R

앞 세 열 (j=0,1,2) 만으로 R = 1, 2, 3 이 전부 모순이다.
  R=1 : j=0 해가 (1,0,0) 또는 (0,1,0) 인데 N_1 >= 2 또는 3 > 1
  R=2 : q_0 = 0 이고 (h_0,p_0) in {(2,0),(1,1),(0,2)} 인데 N_1 >= 4, 5, 6 > 2
  R=3 : j=0 해 다섯 개 중 넷은 N_1 >= 6 이고, 남는 q_0=1 도 N_2 >= 4 > 3
따라서 R >= 4, n = Rw/4 >= w.  아래 구성이 n = w 를 달성하므로 최소다.

**상한.** 유닛 분해 (정리 4 와 같은 논증). T 의 네 회전을 U D L R 로 쓴다.

    적층 유닛 S (폭 4)   U@0  L@2  R@0  D@1      클리어 없이 행 0..3 을 정확히 채움
    마지막 유닛 E_4      U@0  L@2  R@0  D@1
    마지막 유닛 E_5      U@0  D@2  R@0  L@3  D@1
    마지막 유닛 E_6      U@1  L@4  D@2  R@0  D@0  D@3
    마지막 유닛 E_7      U@0  U@3  D@2  L@5  D@4  R@0  D@1

w = 4a + m, m in {4,5,6,7} (w mod 4 = 0,1,2,3 에 대응) 으로 모든 w >= 4 를 덮는다.
열 0 부터 S 를 a 개, 열 4a 부터 E_m 을 놓는다. 조각 수 4a + m = w.  [QED]

**Walkup 과의 관계.** 조건 (a) 가 곧 x x 4 직사각형의 T 타일링이므로 Walkup 에 의해
적층 유닛 폭은 4 의 배수로 강제된다. 정적 타일링이 막는 폭 5·6·7 을 마지막 유닛의
줄 클리어가 정확히 그만큼 메운다. 이 대비가 논문의 중심 문장이다.

덧붙여 4 x 4 타일링이 **중력 아래 순수 적층으로** 실현되는지는 Walkup 이 보장하지 않는다
((L2) 는 정적 타일링의 관심사가 아니다). 그게 이번 탐구의 실질적 관문이었다.

## 보조정리 M (거울 대칭)

보드와 규칙 전체가 좌우 반전에 대해 대칭이다. 어떤 플레이의 모든 배치를
좌우 반전하면 여전히 합법 플레이이고, 클리어 구조도 보존된다.
J 와 L 은 서로의 거울상, S 와 Z 도 서로의 거울상이므로

    L 만으로 PC 가능  <=>  J 만으로 PC 가능
    Z 만으로 PC 가능  <=>  S 만으로 PC 가능

두 쌍은 모든 폭, 모든 n 에서 동일하게 행동한다. **두 쌍을 구별하는 불변량은
존재할 수 없다.**                                                [QED]

**계산 확인 (2026-09-19).** `src/py/jl.py` 가 두 층위를 확인했다.

프로파일 집합이 같다 — 둘 다 `{(1,1,2), (1,3), (2,1,1), (3,1)}`. 같은 프로파일이라도
셀 배치는 다르다 (`(1,3)` 에서 J 는 `(0,0)(0,1)(1,1)(2,1)`, L 은 `(0,1)(1,1)(2,0)(2,1)`).

한 칸 더 나가서, 열 해 중 기하가 **실제로 실현하는 것의 개수까지** 같다.

    w=4 R=2  열 해 1    J 1    L 1
    w=4 R=4  열 해 5    J 3    L 3
    w=4 R=6  열 해 16   J 7    L 7
    w=4 R=8  열 해 29   J 15   L 15
    w=5 R=8  열 해 104  J 66   L 66
    w=6 R=4  열 해 13   J 6    L 6
    w=6 R=8  열 해 490  J 261  L 261

한쪽만 실현하는 해가 한 줄도 없다. w=5 R=4 와 w=6 R=2 는 열 해 자체가 없어서 표에 없고,
이는 `colproof.py` 가 임의 폭에서 확정한 J·L 최소 R (4|w 면 2, 짝수 폭이면 4, 홀수 폭이면 8) 과
정확히 맞는다.

보조정리 M 자체는 `jl.py --fast` 로 즉시 확인되고 `make check` 에 들어 있다.
위 실현 가능성 전수는 w=6 R=8 (해 490 개, 조각 12 개) 때문에 30 분쯤 걸려 `check-full` 로 뺐다.

## 정리 4 (J, L: 모든 폭 w >= 4 에서 가능, 그리고 최소)

열 프로파일 표기: A=(2,1,1)  B=(1,1,2)  P=(1,3)  Q=(3,1)

**유닛.** 각 유닛은 고정된 유한 대상이며, 자기 열 범위 안에만 존재한다.
(열 번호는 유닛의 왼쪽 끝 기준 상대값)

    이름    열수  R   조각수  배치
    AB       4    2    2      A@0, B@1
    PQ       2    4    2      P@0, Q@0
    PQPQ     2    8    4      P@0, Q@0, P@0, Q@0
    UNIT5    5    8   10      A@0 P@1 P@0 P@3 Q@0 Q@3 A@2 A@0 P@3 B@1

**분해.**

    w = 0 (mod 4)   AB 유닛 w/4 개          R=2,  n=w/2
    w = 2 (mod 4)   PQ 유닛 w/2 개          R=4,  n=w
    w 홀수          UNIT5 1 개 + PQPQ (w-5)/2 개    R=8,  n=2w

(홀수 폭은 w = 5 + 2k 로 분해된다. n = 10 + 4k = 2w.)

**증명.**

1. 유닛들은 서로 겹치지 않는 열 구간을 차지하고, 유닛의 모든 조각은 자기 열
   안에만 있다. 따라서 조각의 착지 행은 자기 유닛의 내용만으로 결정된다.

2. 유닛을 왼쪽부터 하나씩 완성한다. 마지막 유닛을 시작하기 전까지는 그 유닛의
   열이 비어 있으므로 꽉 찬 줄이 없고 **클리어가 일어나지 않는다**.
   따라서 각 비-마지막 유닛은 순수 적층으로 자기 열의 행 0..R-1 을 정확히 채운다.
   -> 유닛 타입별 유한 검산 (a).

3. 마지막 유닛을 시작할 때, 그 바깥의 모든 열은 행 0..R-1 이 꽉 차 있고 그 위는
   비어 있다. 따라서 행 j 가 꽉 참  <=>  j < R 이고 마지막 유닛의 열들이 행 j 에서
   꽉 참. 즉 **클리어 조건이 마지막 유닛 자기 열만으로 결정된다.**
   마지막 유닛은 독립 보드에서와 똑같이 진화하며, 클리어를 켠 채로 R 줄을 지우고
   스스로 비워진다.
   -> 유닛 타입별 유한 검산 (b).

4. 3 의 클리어는 전역이므로 다른 유닛의 칸도 함께 제거한다. 보드가 빈다.   [QED]

(a) 와 (b) 는 각각 유닛 타입 4 개에 대한 유한 검산이며 w 에 의존하지 않는다.
units.py 가 둘 다 확인하고, 전체 구성을 폭 4..60 에서 검증한다 (실패 0).

L 은 보조정리 M (거울 대칭) 에 의해 동일.

**최소성.** 열 카운팅의 최소 R 은 w=0 (mod 4) 에서 2, w=2 (mod 4) 에서 4,
w 홀수에서 8 이다. n = Rw/4 는 R 에 단조이므로 위 구성이 최적이다.

    n_min(J) = n_min(L) =  w/2   (w = 0 mod 4)
                           w     (w = 2 mod 4)
                           2w    (w 홀수)

**하한이 임의 폭에서 증명됐다 (2026-09-16).** 그 전에는 colcount.py 를 폭마다 돌린
기계 검증이어서 정리 3(b) 보다 강도가 약했다.

열 카운팅을 왼쪽에서 오른쪽으로 훑는 전이의 상태는 "다음 열들로 이미 넘긴 기여" 이고,
각 성분이 0..R 이므로 상태 공간이 유한하다. 전이는 상태집합 위에서 결정적이므로
도달 가능 상태집합의 수열이 **결국 주기적**이다 (비둘기집). 오른쪽 끝 carrylen 개 열은
놓을 수 있는 프로파일이 제한되지만 그 변환열은 폭에 무관하게 고정이다.
따라서 "폭 w 에서 열 해가 존재하는가" 가 w 에 대해 결국 주기적이고, 주기를 검출하면
모든 폭이 한 번에 결정된다.

    J, L :  R=1  어떤 폭에서도 해 없음
            R=2  w = 0 (mod 4) 에서만
            R=4  w 짝수에서만
            R=8  모든 폭
    => 최소 R = 2 / 4 / 8,  n = w/2 / w / 2w

`src/py/colproof.py`. 주기 논증과 직접 계산이 폭 4..40 에서 0 건 불일치.
같은 도구가 다른 조각도 임의 폭에서 확정한다.

    I  4|w -> R=1 (n=w/4),  그 외 -> R=4 (n=w)
    O  짝수 폭 -> R=2 (n=w/2),  홀수 폭 -> 열 해 없음
    T  모든 폭 -> R=4 (n=w)                     <- 정리 3(b) 하한과 일치
    S, Z  짝수 폭 -> R=2 (카운팅은 통과),  홀수 폭 -> 열 해 없음

S·Z 의 짝수 폭 R=2 가 임의 폭에서 확정됐으므로, 정리 1(b) 의 기하 논증이 모든 짝수 폭에서
필요하다는 것도 임의 폭에서 확정이다 (카운팅만으로는 절대 안 닫힌다).

주: 초기에는 탐색이 찾은 순서 (PPQQ 블록 + 3 열 꼬리) 를 썼으나, 그 순서는
마지막 유닛 밖에서도 클리어가 끼어 블록 독립성이 깨져 사람 증명으로 쓰기 나빴다.
3 열로는 클리어 없는 8 줄 채움이 존재하지 않으므로 (전수 확인) 5 열 유닛이 필요하다.

## 완전 분류

    I     모든 폭 가능           정리 3 (세로 I 를 각 열에 하나씩)
    O     w 짝수만               정리 2 (열 카운팅)
    T     모든 폭 가능 (n = w)   **정리 없음** — 폭별 탐색만 (아래 참고)
    J, L  모든 폭 가능           정리 4
    S, Z  모든 폭 불가능         정리 1, 5

**T 칸의 근거 (2026-09-15 감사).** 다른 여섯 종은 임의 폭 정리가 있는데 T 만 없다.
"모든 폭 가능, n = w" 는 폭 4~14 에서 `./bin/pc3 <w> <w> 4 <w mod 2>` 로 확인한 사실과
n = w 패턴 관찰이며, **임의 폭 구성이나 증명은 아직 없다.**
논문의 중심 대비(Hochberg 하한의 무효화)가 이 칸에 걸려 있으므로 분류에서 가장 약한 자리다.
`pc3` 의 네 번째 인자(원하는 #T 홀짝)는 T 단독에서 #T = n 이므로 `w mod 2` 여야 한다.

**탐색으로는 이 칸을 닫을 수 없다.** `pc3` 의 메모 키가 보드를 8 비트 왼쪽으로 밀어
meta 를 붙이므로 `hcap*w <= 120` 이 한계이고, T 단독은 hcap=8 이라 w <= 15 가 전부다.
감사 전에는 이 검사가 없어서 w=18, 19, 20 이 **거짓 "NO perfect clear"** 를 냈다
(상위 비트가 잘려 서로 다른 상태가 같은 키를 가졌다). 지금은 REFUSED 로 거부한다.
그러므로 임의 폭은 구성·증명으로만 닫힌다.

**S 와 Z 만 불가능하다.** 나머지 다섯 종은 전부 가능.

정적 타일링(Walkup 계열)과의 대비:
  - Walkup: T 로 w x n 직사각형 덮기는 w, n 둘 다 4 의 배수일 때만
  - Hochberg: 폭 5 는 5 열마다, 폭 7 은 7 열마다 모노미노가 반드시 필요
  - 동적: T 는 모든 폭에서 모노미노 0 개로 완전히 비운다
  줄 클리어가 T, J, L 은 풀어주고 S, Z 는 못 풀어준다.

## 카운팅 vs 기하 대조표

각 칸은  (열 카운팅이 허용하는 최소 n) / (실제 최소 n)

    piece    w=4      w=5      w=6      w=7      w=8      w=9      w=10
    I        1/1      5/5      6/6      7/7      2/2      9/9      10/10
    O        2/2      - / -    3/3      - / -    4/4      - / -    5/5
    T        4/4      5/5      6/6      7/7      8/8      9/9      10/10
    S      * 2/불가   - / -  * 3/불가   - / -  * 4/불가   - / -   * 5/불가
    Z      * 2/불가   - / -  * 3/불가   - / -  * 4/불가   - / -   * 5/불가
    J        2/2     10/10     6/6     14/14     4/4     18/18    10/10
    L        2/2     10/10     6/6     14/14     4/4     18/18    10/10

    -  = 카운팅 단계에서 해 없음 (증명된 불가능)
    *  = 카운팅과 기하가 갈리는 지점

**열 카운팅은 S, Z 를 제외한 모든 조각에서 필요충분이다.**
S, Z 만이 카운팅을 통과하고도 기하에서 죽는다. 이 문제에서 기하가
실제로 필요한 유일한 자리이며, 그것이 정리 1 의 가치다.

## 정정 기록 (중요)

이 표는 두 번 틀렸다가 고쳐졌다. 둘 다 실험 하네스의 결함이었고, 증명 쪽은
영향이 없었다.

**(1) T 패리티 인자 실수.** `./pc3 <w> <n> <mask> <T패리티>` 의 마지막 인자에
전 조각 일괄로 0 을 넣었다. T 만 쓰는 n 조각 게임은 #T = n 이므로 n 이 홀수면
요구 패리티가 1 이다. w=7 n=7 을 패리티 0 으로 찾으니 영원히 안 나왔고,
"T 는 홀수 폭에서 불가능" 이라는 잘못된 결론이 나왔다.
오염 범위: T 행. 나머지는 #T = 0 이라 패리티 0 이 옳다.

**(2) 좌우 대칭 정규화 오용.** 상태 수를 줄이려고 보드를 거울상과 비교해
작은 쪽으로 정규화했는데, 이건 **조각 집합이 거울에 닫혀 있을 때만** 유효하다.
L 의 거울상은 J 이므로 L 단독 탐색에서 보드를 뒤집으면 이후의 L 배치가
원래 보드의 J 배치가 된다. dedup 도 서로 다른 분기를 뭉개 해를 놓친다.
이 때문에 L w=4 가 n=4 로 잘못 나왔고 (실제 n=2), 존재하지도 않는
"J 와 L 을 구별하는 불변량" 이 미해결 문제로 기록됐었다.
오염 범위: J·L·S·Z 단독 탐색. I·O·T 단독과 전체 집합은 거울 닫힘이라 무사.
S·Z 는 정리 1 이 독립 증명이라 결론 자체는 유효했다.

수정: `mirrorok = (S비트 == Z비트) && (J비트 == L비트)` 일 때만 정규화 적용.

교훈: 검증 코드가 옳아도 호출이 틀리면 전수 탐색이 못 잡는다.
실험 하네스 자체를 별도로 검산해야 한다. 실제로 (2) 는 C++ 결과와
독립 구현한 Python 결과가 갈려서 잡혔다.

## 두 조각 조합

조각 공급을 우리가 고르므로, 한쪽만으로 PC 가 되면 다른 쪽을 안 쓰면 된다.
I, T, J, L 은 단독으로 모든 폭에서 가능하므로 **이들을 포함한 모든 쌍은 자명하게 가능**.
따라서 비자명한 경우는 세 가지뿐이다.

핵심: S 와 Z 의 열 프로파일 집합은 {(1,2,1),(2,2)} 로 완전히 동일하고,
O 의 (2,2) 는 S 가 이미 갖고 있다. 그래서 아래 세 쌍의 카운팅 방정식은
모두 S 단독과 글자 그대로 같다. 정리 1(a) 가 그대로 적용된다.

    쌍                결과
    I/T/J/L 포함      모든 폭 가능 (한쪽만 사용)
    {O,S}, {O,Z}      짝수 폭만 가능 (n = w/2, O 만 사용). 홀수 폭은 카운팅으로 불가능
    {S,Z}             모든 폭 불가능 (정리 5)

=> 두 조각 조합 분류 완결. 불가능한 쌍은 {S,Z} 하나뿐이고,
   {O,S},{O,Z} 가 홀수 폭에서만 실패한다.

## 세 조각 이상 (2026-09-15 감사에서 정정)

앞서 "세 조각 이상은 불가능 쌍이 하나뿐이므로 자명하게 가능" 이라고 적었으나 **틀렸다.**
{O,S,Z} 는 세 종류인데 홀수 폭에서 불가능하다. 셋의 프로파일 집합이 S 단독과 같은
{(1,2,1),(2,2)} 이므로 정리 1(a) 의 카운팅이 그대로 적용되고, O 의 (2,2) 도 짝수 열로 강제된다.
`./bin/pc3 <w> <w> 26 0` 으로 w=5, 7, 9 확인 — 전부 NO. w=6 은 FOUND (O 만 쓰면 된다).

논증의 구멍은 "불가능 쌍이 하나뿐" 에서 3 종 이상을 결론한 부분이다.
O 자체가 폭 제약을 가지므로 O·S·Z 만 받은 경우가 남는다.

올바른 형태는 부분집합 전체를 덮는 한 문장이다.

    조각 집합 P 가 폭 w 에서 PC 가능  <=>  P ∩ {I, T, J, L} != 빈집합,
                                        또는 (w 짝수이고 O ∈ P)

  - P 가 I·T·J·L 중 하나를 포함하면 그것만 써서 가능 (T 는 확인된 폭 범위 안에서)
  - 아니면 P ⊆ {O,S,Z} 이고 카운팅이 S 단독과 같다.
    홀수 폭은 전부 불가능. 짝수 폭은 O ∈ P 면 가능, 아니면 정리 1·5 가 막는다.

원래 표보다 강한 진술이며 2 종·3 종·전 부분집합(2^7 가지)을 한꺼번에 덮는다.

실험: w=4..10, n<=12 에서 {S,Z} 는 전 범위 불가능. {O,S},{O,Z} 는 짝수 폭 n=w/2.

### 정리 5 ({S,Z}: 모든 폭에서 불가능)

**환원.** 카운팅이 "가로 없음, 세로만, 짝수 열에만" 을 강제하므로 (S 와 Z 의
프로파일 집합이 {(1,2,1),(2,2)} 로 동일하여 정리 1 의 유도가 글자 그대로 적용된다)
모든 조각이 블록 (c, c+1) (c 짝수) 안에 갇힌다. 착지 높이는 그 블록 내용만으로
결정되고, 전역 클리어는 그 블록에서도 꽉 찬 줄에서만 일어난다.
w/2 개의 2 열 블록이 독립 진화하며, 보드 행 0 이 꽉 참 <=> 모든 블록의 행 0 이 꽉 참.
=> 폭 w 문제가 폭과 무관한 2 열 문제로 환원된다.

**설정.** 블록의 두 열을 F0, F1 (채워진 행 집합), t = 최상단 비지 않은 행,

    d_j     = |F0 ∩ [0,j]| - |F1 ∩ [0,j]|
    delta_j = d_j - d_(j-1)  ∈ {-1, 0, 1}

행 라벨: delta_j = +1 -> A (열0 만), -1 -> B (열1 만), 0 -> E (빔) 또는 F (꽉 참).

전이:
    Z 를 r 에 : F0 += {r,r+1}, F1 += {r+1,r+2}   ->  d_r += 1, d_(r+1) += 1
    S 를 r 에 : F0 += {r+1,r+2}, F1 += {r,r+1}   ->  d_r -= 1, d_(r+1) -= 1
    행 m 클리어 : 수열에서 d_m 을 삭제. 값은 하나도 바뀌지 않는다.

세로 S 의 모양은 왼쪽 열 상대행 {1,2} / 오른쪽 열 {0,1}, 세로 Z 는 그 거울상.

**I0 : |F0| = |F1|.**
조각은 각 열에 2 칸, 클리어는 각 열에서 1 칸. 0 에서 시작하므로 항상 같다.
따라서 j >= t 에서 d_j = 0.                                              [QED]

**I1 : 내부에 빈 줄이 없다 (행 0..t 가 전부 비지 않음).**
조각의 최하단 칸은 행 r 에 있다. r-1 > t 라면 r-1 에 놓아도 모든 칸이 t 위라
충돌이 없으므로 더 내려간다. 따라서 r <= t+1.
조각은 행 r, r+1, r+2 를 모두 비지 않게 만들고 귀납 가정으로 0..t 가 차 있으니
빈틈이 안 생긴다. 클리어는 연속 구간에서 몇 줄을 빼고 압축하므로 역시 못 만든다.
=> 라벨 E 는 어떤 도달 가능 상태에도 등장하지 않는다.
=> 단어가 d 수열로 완전히 결정된다 (delta = 0 이면 반드시 F).           [QED]

**I2 : |d_j| <= 1.**
Z 를 r 에 놓기 직전에 d_r <= 0 임을 보이면 된다.
Z 의 전제조건상 (r,0) 이 비어 있다.
  - r <= t 면 I1 에 의해 행 r 이 비지 않았고 (r,0) 이 비었으니 r ∈ F1.
    따라서 delta_r = -1 이고 d_r = d_(r-1) - 1 <= 0.
  - r = t+1 이면 I0 에 의해 d_(r-1) = d_t = 0 이고 행 r 이 비었으니 d_r = 0.
  - r > t+1 은 I1 증명에서 불가능.
(r+1,0) 과 (r+1,1) 이 둘 다 비어 있으므로 delta_(r+1) = 0, 즉 d_(r+1) = d_r <= 0.
두 값에 +1 을 해도 <= 1. S 는 거울상. 클리어는 값을 바꾸지 않는다.      [QED]

**I3 : 보드가 비지 않았으면 d_0 != 0.**
d_0 은 r = 0 착지로만 바뀐다. 첫 조각이 d_0 = ±1 로 만든다.
이후 d_0 = +1 (행 0 = A) 이라 하자.
  - Z 는 r=0 불가 : (0,0) 이 차 있다.
  - S 는 r=0 불가 : I2 에서 d_1 ∈ {0,1}. I0 에 의해 F1 이 비지 않고 0 ∉ F1 이므로
    t >= 1, 따라서 I1 로 행 1 이 비지 않았다.
      d_1 = 0 -> delta_1 = -1 -> 행1 = B
      d_1 = 1 -> delta_1 =  0 -> 행1 = F   (E 는 I1 로 배제)
    둘 다 (1,1) 이 차 있다 -> S 충돌.
따라서 첫 조각 이후 어떤 조각도 r=0 에 놓이지 못한다.
클리어도 d_0 을 바꾸지 못한다: 행 m 클리어는 수열에서 d_m 만 지우고 나머지 값을 안 바꾸므로
m > 0 이면 d_0 이 그대로이고, m = 0 은 d_0 = 0 을 요구하므로 귀납 가정이 배제한다.
(2026-09-15 감사에서 이 단계가 빠져 있어 보강.) 그래서 d_0 은 ±1 로 고정된다.  [QED]

**정리 5.** 행 0 이 꽉 참 <=> delta_0 = d_0 = 0 이면서 비지 않음.
I3 이 이를 배제한다. 따라서 행 0 은 절대 꽉 차지 않고, 절대 클리어되지 않는다.
첫 조각이 행 0 에 남긴 칸은 영구히 제거 불가.
=> {S, Z} 만으로는 어떤 폭에서도 퍼펙트 클리어가 불가능하다.            [QED]

검증: H=18 의 도달 가능 블록 상태 7,141 개 전부에서 (H=12/14/16 은 397/1,041/2,727 개.
7,141 은 H=18 단독 개수이고 세 H 의 합이 아니다. 검산기는 `src/py/szinv.py` —
`szlang.py` 는 상태·단어만 세고 불변량을 검사하지 않는다. 2026-09-15 독립 구현으로 재확인)
I0, I1, I2, I3 위반 0. szlang.py 는 도달 가능 상태를 라벨 단어로 출력하며,
언어가 F 삭제에 닫혀 있음 (= 클리어 연산) 도 확인된다.

**따름정리.** Burgiel 정리 (S/Z 교대 수열은 필패) 의 극단 버전:
S 와 Z 만으로는 이기기는커녕 보드를 비우는 것조차 불가능하다.

## 열린 문제

   더해도 가능해진다 (그 조각 단독으로 되니까). 즉 3 조각 이상은 자명.
