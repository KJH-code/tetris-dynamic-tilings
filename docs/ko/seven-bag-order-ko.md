# 7-bag 순서 제약 하의 퍼펙트 클리어 (w=10, n=10)

## 설정

    폭 10, 10 조각, R = 4 줄.
    조각은 bag1 (7 종 순열) -> bag2 (7 종 순열) 순으로 도착.
    홀드 1 칸, 표준 규칙.
    하드드롭 전용 (턱/스핀 없음)  => 결과는 보수적:
      "가능" 은 실제 테트리스에서도 반드시 가능
      "불가능" 은 우리 모델 한정 (스핀을 쓰면 뚫릴 수 있음)

10 회 배치에 소비하는 도착 조각은 최대 11 개 (홀드에 하나 남길 수 있으므로).
따라서 bag2 는 앞 4 개만 관여한다 -> bag2 접두사 P(7,4) = 840 가지.

    SLOZ  LSOZ              <- 가능 (...OZ)

반례가 나왔다 (아래 절). 조각 집합 쪽 관찰({O,S,Z}+{J 또는 L})만 살아남았다.

bag1 = T J L I S Z O 자체가 S, Z, O 로 끝난다. S/Z 가 뒤에 몰리면 계단이 쌓이고
4 줄 안에서 풀 수단이 소진되는 구조로 보인다. Burgiel 정리가 가리키는 방향과 같다.

우리 모델 (하드드롭 전용) 에서의 불가능이다. 스핀/턱을 허용하면 달라질 수 있으므로
"실제 테트리스에서 불가능" 이라고 주장하면 안 된다.

## 정리 H (홀드 교환 불변) — 2026-09-19 증명

`ITJLSZO` 와 `TIJLSZO` 가 네 접두사에서 상태 수까지 같았던 것이 출발점이었다.
관찰이 아니라 정리다. **전체 증명은 볼트 `7-bag.md` §정리 H 에 있다.** 여기는 요약이다.

`fix4` 의 규칙에서 상태 (B, i, h) 의 수는 셋뿐이다.

    (S)  h = 비었을 때만:  (B, i+1, q_i)      아무것도 안 놓고 홀드에 넣는다
    (P0)                   (B', i+1, h)        B' 는 q_i 를 떨어뜨린 보드
    (P1) h 가 찼을 때만:   (B', i+1, q_i)     B' 는 h 를 떨어뜨린 보드

**보조정리 1.** (P0) 은 홀드를 유지하고 (P1)·(S) 는 홀드를 채운다. 홀드는 비어 시작한다.
→ 홀드가 빈 구간은 앞 구간뿐이고 한 번 차면 다시 비지 않는다. (S) 는 **많아야 한 번**.

**보조정리 2.** 도착이 배치보다 하나 이상 많으면 (L ≥ n+1) 모든 플레이가 k=0 스태시에 흡수된다.

    Plays_n(q) = q_1 · HG(q_0 ; q_2 q_3 …)  ∪  q_0 · HG(q_1 ; q_2 q_3 …)

열쇠는 "홀드를 뱉고 들어온 것을 홀드에 넣는" 수를 되풀이하면 도착 순서가 그대로
재현된다는 것이다. 스태시 없는 플레이도, k≥2 스태시도 전부 이걸로 우변에 들어간다.
이때 도착 q_n 이 필요하고, **L ≥ n+1 은 여기서만 쓰인다.**

**정리 H.** 우변이 q_0, q_1 에 대칭이다 → 첫 두 조각을 바꿔도 달성 가능한 배치 수열 집합이
같고, 따라서 PC 가능 여부도 같다.

### 따름정리

- **첫 조각은 무조건 홀드에 넣고 시작해도 손해가 없다** (Plays = S_0).
- 5040 개 bag1 이 빠짐없이 짝을 이룬다 → 동치류 **2,520 개**, 전수 비용이 정확히 절반.
- 표본 100 개 중 실질적으로 다른 문제는 **98 개**. 실패 bag1 셋의 교환쌍
  (JLTIOZS, OLTJISZ, LTJOISZ)도 반드시 실패하므로 나쁜 bag1 의 개수는 **짝수**다.
- **가설이 날카롭다.** L = n 이면 (S) 가 불가능해 플레이가 하나로 고정된다.
  공허하지 않다 — 홀드 없는 모델에서 첫 두 글자만 바꿔 답이 갈리는 수열이
  w=4 n=4 에서만 **66 쌍** 있다 (`OTTJ` 불가능 / `TOTJ` 가능).
  **이 불변성은 홀드가 아니라 "여분 도착 한 칸" 이 만든다.**

### 계산 근거 (`data/holdswap.out`)

성공 케이스 1,684 건에서 판정도 상태 수도 전부 일치했다. **상태 수까지 같은 건 정리보다
강한 현상이고 증명이 그것도 설명한다** — k=0 스태시 부분트리가 두 수열에서 그래프로서
동일하고, `fix4` 가 스태시를 먼저 시도하므로 성공은 그 안에서 끝난다.

반면 스태시 없는 가지는 동일하지 않다 (세로 I 를 놓고 O 를 얹은 보드는 O 를 먼저 놓아서는
안 나온다). 그 가지는 **실패할 때만** 끝까지 훑린다. 그래서 예측을 적고 검정했다.

    LJTIOZS + OLSZ    no PC   38,542,538 상태
    JLTIOZS + OLSZ    no PC   38,537,388 상태     차이 5,150

판정은 같고 상태 수는 다르다. **예측 통과.** 이 검정이 없었다면
"상태 수까지 항상 같다" 를 정리의 일부로 오해했을 것이다.

## 구현 신뢰도

세 구현을 교차 검증했다.

    fix2.cpp   unordered_set<__int128>            키 = (보드, i, 홀드, mask2)
    fix4.cpp   개방 주소법 + 64 비트 지문, 2^27   키 = (보드, i, 홀드)
    fix5.cpp   개방 주소법 + 완전한 128 비트 키, 2^26

소규모 케이스에서 상태 수까지 정확히 일치. 대규모에서 fix2 가 약 2.6% 많은
상태를 세는데, 원인은 fix2 의 mask2 갱신이 경로마다 다르기 때문 (배치 분기는
갱신, 스태시 분기는 미갱신). mask2 는 bag2 순서 고정 이후 로직에 쓰이지 않고
메모 키에만 들어가므로, 같은 실제 상태가 중복 등록될 뿐 답은 같다.
fix4 와 fix5 는 정확히 일치하므로 지문 해싱 자체는 무해하다.

지문 계산에 잠재 버그가 하나 있었다: b (보드 상위 16 비트) 와 (i<<8)|hold 를
XOR 하면 비트가 겹쳐 조직적 충돌이 생긴다. b | (k << 16) 으로 분리해 수정했다.
이번 케이스들에서는 실제 충돌이 없었으나 (수정 전후 상태 수 동일) 구조적 결함이었다.

fix5 가 LOZS 에서 46,976,203 상태로 INCONCLUSIVE 를 냈는데
이는 2^26 * 0.7 = 46,976,204 와 일치하는 테이블 적재율 한계였다.
테이블이 두 배인 fix4 로 재실행해 완결했다. 숫자 일치 확인이 중요하다.

## 읽는 법

세 변수가 차례로 거의 닫혔다. 조각 구성은 전혀 장애물이 아니고, bag1 순서도
(bag2 가 자유라면) 장애물이 아니다. 양쪽을 다 고정했을 때 비로소 드물게 실패가 나온다.
표본 100 개 전수 기준 실패율은 **1.1×10⁻⁴** 이고, 하드드롭 제한이 걸린 값이므로
실제 규칙에서는 더 낮다. 5040 전체의 정확한 값은 아직 열린 문제다.

=> **PCO, Jaws, 3 피스 오프너 같은 여러 셋업이 존재하는 이유는 "PC 가 없어서" 가 아니다.**
   PC 는 거의 항상 존재한다. 오프너는 존재성 문제의 답이 아니라
   **탐색 비용과 암기 비용** 문제의 답이다. 특정 셋업을 고정해 쓰기 때문에
   실전 성공률이 100% 에 못 미치는 것이지, 해가 없어서가 아니다.

## I 위치를 정리로 만들려던 시도 (2026-09-21)

"I 가 늦으면 어렵다" 의 자연스러운 정리 형태는 **거짓**이다. 대신 셋을 얻었다.

### 보조정리 P — 배치열의 사슬 특성화

보드는 배치열이 정해지면 따라오므로 배치열 집합 `Plays_n(q)` 만 보면 된다.
첫 도착을 무조건 홀드에 넣어도 손해가 없으니(정리 H 따름정리 H1)
도착을 `a_0`(처음부터 홀드) 와 스트림 `a_1 … a_m` 으로 본다.

> 홀드를 뱉는 자리 `j_1 < … < j_r` 하나가 플레이 하나다. 자리 `j_k` 에는
> `a_{j_{k-1}}` 이 나오고(`j_0 = 0`), 사슬 밖 자리 `j` 에는 `a_j` 가 그대로 나온다.
> 끝에 홀드에 남는 것은 `a_{j_r}`.

**한 번에 하나만 미룰 수 있고, 미룬 것을 내보내면 그 자리의 것이 새로 미뤄진다.**
검산 `python3 src/py/plays.py 5` — 규칙 재귀와 사슬 공식이 4,922 비교에서 불일치 0.

### 보조정리 Q — 인접 교환은 맨 앞에서만 대칭

`q_i ↔ q_{i+1}` 교환이 Plays 를 보존하는 것은 **i = 0 뿐이다.**
i=0 은 사슬 대응 `C ∖ {1}` ↔ `C ∪ {1}` 로 보존되는데, 이것이 **정리 H 의 두 번째 증명**이다.
i ≥ 1 은 L=3..7 전 자리에서 전부 깨진다 (두 집합 크기는 같다).

정리 H 가 특별했던 이유가 여기서 보인다 — **맨 앞에서만 홀드가 비어 있어
두 조각이 대칭이고, 그 뒤로는 이미 홀드에 뭔가 들어 있다.**

### "I 를 한 칸 앞으로 당기면 이득" 은 거짓 (68/72)

`wxyz S I Z`(I 6 번째) → `wxyz I S Z`(I 5 번째), `{w,x,y,z} = {T,J,L,O}` 24 가지 ×
접두사 3 개 = 72 쌍. **68 쌍이 가능 → 불가능**, 양쪽 불가능 4, **양쪽 가능 0.**

### 닫힌 가족 — 72 건 전부 불가능

> `bag1 = (T,J,L,O 의 임의 순열) + I S Z`, `bag2 ∈ {JOZS, JZOS, OJZS}`
> ⇒ 퍼펙트 클리어 불가능. 24 × 3 = 72 건 전부. 미결 0.

재현 `python3 scripts/ipos-family.py`. 대칭으로 접을 때 **거울은 bag2 도 같이 바꾼다.**

### 정적 불변량은 배제된다

    TJILSZO + OJZS    가능    20,275,435 상태
    TJLISZO + OJZS    불가능  36,891,439 상태

**도착 multiset 이 같은데 판정이 갈린다.** 따라서 놓인 조각의 multiset 만 보는
불변량 — 동적 T-패리티, 열 카운팅, Walkup 류 — 은 이 문제를 결정할 수 없다.
위 가족의 증명은 **도달성 논증이어야 한다.**
