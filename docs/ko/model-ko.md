# 모델의 형식적 정의와 의존도 분석

논문 2 절에 들어갈 내용. 어떤 결과가 모델 의존이고 어떤 게 아닌지 못 박는다.

## 1. 보드와 배치

폭 w >= 2 의 보드. 상태는 유한 집합

    B ⊆ {0, 1, ..., w-1} x Z_{>=0}

행 0 이 바닥. (r, c) ∈ B 는 "행 r, 열 c 가 채워짐".
게임은 B = ∅ 에서 시작한다.

조각 종류의 집합 P ⊆ {I, O, T, S, Z, J, L} 가 주어진다.
각 종류는 회전에 의해 생기는 **셀 집합들** (평행이동 무시) 의 유한 집합을 가진다.

한 수 (move) 는 다음으로 이루어진다.
  - P 에서 종류 하나를 **자유롭게** 고른다 (조각 공급에 제약 없음)
  - 그 종류의 셀 집합 하나와 보드 위 위치 하나를 고른다
  - 그 결과 놓인 4 칸 집합을 X 라 하자

X 는 아래 두 조건을 만족해야 한다.

    (L1)  X ∩ B = ∅              모든 칸이 비어 있다
    (L2)  X 를 한 칸 아래로 내린 X-1 에 대하여
          X-1 ⊄ (보드 내부의 빈 칸)   즉 X 는 더 내려갈 수 없다
          (바닥에 닿았거나, 아래에 막힌 칸이 있다)

놓은 뒤 B := B ∪ X 로 갱신하고, 곧바로 줄 클리어를 적용한다.

    (L3)  꽉 찬 행 (그 행의 w 칸이 모두 채워진 행) 을 **동시에 모두** 제거하고,
          각 칸은 자기 아래에서 제거된 행의 개수만큼 내려간다.

**퍼펙트 클리어 (PC).** 빈 보드에서 시작해 유한 번의 수 뒤에 B = ∅ 이 되는 것.
클리어로만 칸이 사라지므로, 총 조각 수 n 과 총 클리어 줄 수 R 은 4n = Rw 를 만족한다.

## 2. 모델 변형

(L2) 는 "조각은 받쳐진 상태에서만 고정된다" 는 것만 말하고, **어떻게 거기 도달했는지**
는 말하지 않는다. 실제 구현들은 도달 가능한 X 의 범위가 다르다.

    HD   하드드롭 전용. 회전 후 열을 고르고 수직 낙하.
         X 는 위에서 수직으로 내려와 닿을 수 있는 위치로 한정.
    SD   소프트드롭 + 수평 이동 허용 (턱). 오버행 아래로 밀어넣을 수 있다.
    SRS  회전 킥 허용. 스핀 (T-스핀, S-스핀 등) 으로 더 많은 X 가 가능.

    HD 의 허용 배치 ⊆ SD ⊆ SRS

우리 탐색기는 전부 **HD** 로 구현했다 (pc3.cpp 의 착지 규칙:
r 을 위에서 시작해 r-1 에서 충돌이 없는 동안 감소).

## 3. 의존도 — 핵심

**가능성 (구성) 결과는 위로 전달된다.**
HD 에서 구성한 PC 는 SD, SRS 에서도 그대로 유효하다 (허용 배치가 더 넓으므로).

**불가능성 결과는 일반적으로 전달되지 않는다.**
단, 증명이 (L1), (L2), (L3) 만 쓰고 도달 경로를 쓰지 않으면 전 모델에서 유효하다.

우리 증명들이 실제로 쓰는 가정은 셋뿐이다.

    (i)   놓인 조각의 4 칸은 놓기 직전에 모두 비어 있었다            = (L1)
    (ii)  놓인 조각은 한 칸 아래로 못 내려간다                        = (L2)
    (iii) 꽉 찬 행이 동시에 제거되고 위가 내려온다                    = (L3)

## 4. 결과별 판정

    결과                          종류      쓰는 가정          모델 의존?
    보조정리 0 (열 카운팅)        조합론    (iii) 만            없음
    보조정리 M (거울 대칭)        대칭      보드 대칭성         없음
    정리 1 (S, Z 단독 불가능)     불가능    (i), (ii), (iii)    **없음**
    정리 2 (O: 짝수 폭만)         양쪽      보조정리 0 + 구성   없음
    정리 3 (I: 전 폭 가능)        구성      HD 구성             없음 (위로 전달)
    정리 4 (J, L: 전 폭 가능)     구성      HD 구성             없음 (위로 전달)
    정리 5 ({S,Z} 불가능)         불가능    (i), (ii), (iii)    **없음**

세부 근거:

- **보조정리 0.** 칸은 열을 바꾸지 않고, 클리어 1 회는 모든 열에서 정확히 1 칸을
  제거한다. 최종 보드가 비므로 각 열에 놓인 총 칸 수 = R. (iii) 만 사용.

- **정리 1(b).** 세로 S 의 왼쪽 열 셀은 상대행 >= 1 이다 — 이는 조각의 **모양**
  이지 도달 경로가 아니다. 보조정리 0 이 세로/짝수 열을 강제하므로 (0,0) 은
  어떤 배치로도 채울 수 없다 ((i) 위반이 아니라 애초에 그런 셀 집합이 없다).
  첫 조각이 행 0 을 점유하는 것은 (ii) 에서 나온다 (빈 보드에서는 바닥까지 내려간다).

- **정리 5.** 네 불변량이 쓰는 것:
    I0  (iii)
    I1  (ii) 만 사용. "조각의 최하단 칸이 행 r 이고 r-1 > t 이면, 행 r-1 의
        모든 칸이 비어 있으므로 한 칸 더 내려갈 수 있다" -> (ii) 위반.
        따라서 r <= t+1. 도달 경로 무관.
    I2  I1 + (i)
    I3  I0, I1, I2 + (i). "(1,1) 이 차 있으므로 세로 S 를 r=0 에 놓을 수 없다" 는
        충돌 논증이며, 킥으로 비틀어 넣어도 그 칸은 여전히 점유되어 있다.
  => SRS 를 포함한 모든 모델에서 유효.

- **최소 n.** 하한은 보조정리 0 (모델 무관) 에서 나오고, HD 구성이 그 하한을
  달성한다. 따라서 **최소 n 은 모든 모델에서 같다.**

## 5. 결론

    이 분류는 모델에 의존하지 않는다.

가능성은 HD 구성으로 보였고 (더 넓은 모델로 전달), 불가능성은 (i),(ii),(iii)
만으로 증명했다 (더 넓은 모델에서도 유효). 최소 n 도 일치한다.

따라서 "하드드롭 전용" 이라는 단서는 **탐색 구현의 성질**이지 결과의 단서가 아니다.
논문에서는 (L1)-(L3) 으로 모델을 정의하고, HD/SD/SRS 는 그 구체화로 언급만 한다.

## 6. 명시적으로 다루지 않는 것

    - 조각 공급 제약 (7-bag, 랜덤 생성기). 우리는 종류를 자유롭게 고른다.
    - 홀드, 다음 조각 미리보기, 시간 제약, 중력 속도, 락 딜레이.
    - 보드 높이 상한 (게임 오버). 우리 보드는 위로 무한하다.
      탐색에서 쓴 높이 캡은 h_max <= 4n/w - C_k (클리어 1 회는 최고 높이를
      정확히 1 낮추고 조각 배치는 못 낮춘다) 로 정당화되며 결과를 제한하지 않는다.
    - "모든 종류를 반드시 한 번 이상 사용" 같은 변형.

이들은 열린 문제로 남는다. 특히 7-bag 제약 하의 분류는 실전 테트리스에
가장 가깝고, MIT Hardness Group 2026 이 7-bag NP-hardness 를 다뤘으므로 맥락이 있다.
