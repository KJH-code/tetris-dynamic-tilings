# T 단독, 임의 폭 — 닫힘

2026-09-16. 2026-09-15 감사에서 나온 구멍을 메웠다.
다른 여섯 종은 임의 폭 정리(정리 1~5)가 있는데 **T 만 없었다.**
분류표의 "T 모든 폭 가능 (n = w)" 는 폭 4~14 탐색과 n = w 패턴 관찰뿐이었다.

탐색으로는 닫을 수 없었다. `pc3` 는 메모 키가 보드를 8 비트 미는 탓에 `hcap*w ≤ 120` 이 한계이고
T 단독은 hcap=8 이라 w ≤ 15 가 전부다. 구성·증명만이 길이었고, 그 길로 닫혔다.

## 결과

재혁 결정 (2026-09-16): **정리 3 에 합친다.** 범위는 **존재성 + 최소성 둘 다.**

> **정리 3(b) (T: 모든 폭에서 가능, 그리고 최소).**
> T 단독은 모든 폭 w ≥ 4 에서 퍼펙트 클리어를 허용하고, 최소 조각 수는 **n = w** (R = 4) 다.

## 하한 (R ≥ 4, 임의 폭)

보조정리 0 에서 n = Rw/4 이므로 R ≥ 4 만 보이면 된다.
T 의 열 프로파일은 가로 (1,2,1), 세로 (1,3) 과 (3,1) 셋뿐이다.

    h_c = 왼쪽 열이 c 인 가로 T 개수        (c, c+1, c+2 에 1, 2, 1 칸)
    p_c = (1,3) 세로 T 개수                 (c 에 1 칸, c+1 에 3 칸)
    q_c = (3,1) 세로 T 개수                 (c 에 3 칸, c+1 에 1 칸)

열 j 에 놓인 총 칸 수는

    N_j = h_j + 2h_(j-1) + h_(j-2) + p_j + 3p_(j-1) + 3q_j + q_(j-1) = R

앞 세 열만 쓴다 (w ≥ 3 이면 존재한다).

    j=0 :  h_0 + p_0 + 3q_0 = R
    j=1 :  h_1 + 2h_0 + p_1 + 3p_0 + 3q_1 + q_0 = R
    j=2 :  h_2 + 2h_1 + h_0 + p_2 + 3p_1 + 3q_2 + q_1 = R

**R=1.** j=0 의 해는 (h_0,p_0,q_0) = (1,0,0) 또는 (0,1,0).
전자는 N_1 ≥ 2h_0 = 2 > 1, 후자는 N_1 ≥ 3p_0 = 3 > 1. 모순.

**R=2.** 3q_0 ≤ 2 이므로 q_0 = 0 이고 (h_0,p_0) ∈ {(2,0),(1,1),(0,2)}.
각각 N_1 ≥ 2h_0 + 3p_0 = 4, 5, 6 > 2. 모순.

**R=3.** j=0 의 해는 (3,0,0), (2,1,0), (1,2,0), (0,3,0), (0,0,1).
앞 넷은 N_1 ≥ 2h_0 + 3p_0 = 6, 7, 8, 9 > 3 으로 모순.
남는 것은 q_0 = 1, h_0 = p_0 = 0 뿐이고, 그러면
N_1 = h_1 + p_1 + 3q_1 + 1 = 3 → h_1 + p_1 + 3q_1 = 2 → q_1 = 0,
(h_1,p_1) ∈ {(2,0),(1,1),(0,2)}.
그런데 N_2 ≥ 2h_1 + 3p_1 = 4, 5, 6 > 3. 모순.

따라서 **R ≥ 4** 이고 n = Rw/4 ≥ w. 아래 구성이 n = w 를 달성하므로 최소다.

세 열 방정식의 정수해를 전수로 세어 교차검증했다: R=1·2·3 은 해 **0 개**, R=4 는 10 개.

2026-09-16 추가: `src/py/colproof.py` (전이 집합의 주기 검출로 임의 폭을 판정)가
독립적으로 같은 결론을 낸다 — T 는 R=1·2·3 에서 **어떤 폭에서도 열 해가 없고** R=4 는 모든 폭.
손 유도는 앞 세 열만 쓰는 짧은 논증이고, 주기 검출은 조각·R 을 바꿔도 통하는 일반 도구다.

## 상한 (구성)

정리 4 와 같은 유닛 분해다. 유닛의 열 구간이 겹치지 않고 조각이 자기 열을 안 벗어나므로
착지가 유닛 내용만으로 결정된다.

T 의 네 회전을 라벨로 쓴다.

    U  (0,0)(0,1)(0,2)(1,1)   프로파일 (1,2,1), 꼭지 위
    D  (0,1)(1,0)(1,1)(1,2)   프로파일 (1,2,1), 꼭지 아래
    L  (0,1)(1,0)(1,1)(2,1)   프로파일 (1,3)
    R  (0,0)(1,0)(1,1)(2,0)   프로파일 (3,1)

**적층 유닛 S** (폭 4, 조각 4 개): `U@0  L@2  R@0  D@1`
클리어 없이 행 0..3 을 정확히 채운다.

**마지막 유닛 E_m** (폭 m, 조각 m 개)

    E_4  U@0  L@2  R@0  D@1                  (= S. 클리어를 켜면 4 줄을 지운다)
    E_5  U@0  D@2  R@0  L@3  D@1
    E_6  U@1  L@4  D@2  R@0  D@0  D@3
    E_7  U@0  U@3  D@2  L@5  D@4  R@0  D@1

**조립.** w ≥ 4 를 w = 4a + m, m ∈ {4,5,6,7} 으로 쓴다
(w mod 4 = 0,1,2,3 → m = 4,5,6,7. a ≥ 0). 열 0 부터 S 를 a 개 깔고, 열 4a 부터 E_m 을 놓는다.

**증명.**
1. 마지막 유닛 전까지는 E_m 의 열이 비어 있어 어떤 행도 꽉 차지 않는다
   → 클리어가 안 일어나고 S 들이 순수 적층으로 각자의 행 0..3 을 채운다.
2. E_m 시작 시 바깥(열 0..4a-1)은 행 0..3 이 꽉 차 있다. 따라서 행 j 가 보드 전체에서 꽉 참
   ⟺ E_m 이 자기 열에서 행 j 를 채움. 클리어 조건이 자기 열만으로 결정되므로
   E_m 은 **독립 폭 m 보드에서와 글자 그대로 같게** 진화해 4 줄을 지우고 비워진다.
   그 클리어가 S 들의 행도 함께 지우므로 보드 전체가 빈다.

1 과 2 는 유닛 다섯 개(S, E_4..E_7)에 대한 **유한 검산이며 w 에 의존하지 않는다.**
조각 수는 4a + m = w 로 하한과 일치한다. ∎

### Walkup 과의 관계 (여기가 재미있는 자리)

조건 1 이 요구하는 것은 **4 × 4 직사각형의 T 타일링**이다. Walkup(1965)에 따라
x × 4 직사각형은 4 | x 일 때만 T 로 덮이므로, 적층 유닛의 폭은 4 의 배수여야 한다.
그래서 폭 5·6·7 은 적층 유닛으로 못 만들고 **마지막 유닛(클리어를 쓰는 쪽)이 담당한다.**
정적 타일링이 막는 폭을 줄 클리어가 정확히 그만큼 메우는 구조다.

덧붙여 4 × 4 타일링이 **중력 아래 순수 적층으로** 실현되는지는 Walkup 이 말해주지 않는다
((L2) 지지 조건은 정적 타일링의 관심사가 아니다). 이게 이번 탐구의 실질적 관문이었고,
`U@0 L@2 R@0 D@1` 이 그걸 만족한다. 손으로 추적한 기록:

    U@0   행0 {0,1,2}, 행1 {1}
    L@2   (0,3) (1,2) (1,3) (2,3)        행 0 이 꽉 차지만 클리어는 아직 안 켠다
    R@0   (1,0) (2,0) (2,1) (3,0)
    D@1   (2,2) (3,1) (3,2) (3,3)        → 행 0..3 정확히 16 칸

## 재혁의 접근 (2026-09-16 인터뷰 기록)

노트에 없던 정보라 그대로 남긴다. 결과적으로 **맞는 그림이었다.**

- **"손으로 한 번 해봤다. 체계적이지 않아서 정확하지 않다."** 어느 폭이었는지는 기억 없음.
- **"구조는 자명하다. n×m 박스를 생성해서 dp 와 비슷하게 하면 된다."**
  더 캐물은 결과: **"박스가 높이 h, 너비 x1 이면, x1, x2, x3 … 를 조합해서 w 를 맞추면 된다."**
  → 실제 증명이 정확히 이 구조다. 높이 h = R = 4 고정, 유닛 폭 4 와 m ∈ {4,5,6,7} 의 조합.
- Walkup 제약을 알고 있었냐고 묻자 **"다이나믹 시스템(라인 클리어)으로 채워짐."**
  → 이것도 맞았다. 정적으로 못 채우는 폭을 마지막 유닛의 클리어가 메운다.
  다만 유닛 조합에서 **클리어를 쓰는 유닛은 마지막 하나뿐**이라는 제약이 붙는다.
  나머지 유닛은 순수 적층이어야 하므로 Walkup 때문에 폭이 4 의 배수로 강제된다.
- T 에 정리를 안 쓴 이유는 **기억 없음** (9 월 12~15 일 세션이 길었다).
