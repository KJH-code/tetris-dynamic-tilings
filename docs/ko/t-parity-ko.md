# 동적 T-패리티 불변량 (모든 폭)

MSE 80246의 가설(퍼펙트 클리어 시 T 개수는 짝수)은 거짓. 줄 클리어가
체커보드 색 할당을 뒤집기 때문. 아래가 그 자리에 들어가는 올바른 일반형.

## 기호

    φ(B) = Σ_{(r,c) ∈ B} (-1)^(r+c)          r = 바닥부터 센 행

조각별 기여: T만 ±2, 나머지 6종은 모든 회전에서 0 (흑2 백2).

클리어 이벤트 하나가 줄 j_1 < ... < j_k 를 지운다고 하자.
지워진 줄들 사이의 잔여 구간을 "블록"이라 하고, 블록 b 아래에 있는
지워진 줄의 수를 s_b 라 한다. 블록 b 는 s_b 칸 내려오므로 부호가 (-1)^(s_b) 배.

    D = Σ_i (줄 j_i 위의 칸 수, 단 꽉 찬 줄은 제외)
    A = Σ_i φ(줄 j_i) = (w 홀수면) Σ_i (-1)^(j_i),  (w 짝수면) 0

w 짝수에서 A = 0 인 이유: 꽉 찬 줄의 φ 는 Σ_{c=0}^{w-1} (-1)^(j+c) 이고
안쪽 합이 w 짝수일 때 0.

## 정리 (per-event)

    Δφ_clear  ≡  -2D - A   (mod 4)

증명 스케치:
    φ_pre  = Σ_b φ_b + Σ_i φ(줄 j_i)
    φ_post = Σ_b (-1)^(s_b) φ_b
    Δφ     = Σ_b ((-1)^(s_b) - 1) φ_b - A = -2 Σ_{s_b 홀수} φ_b - A
임의의 집합에서 칸 수 ≡ φ (mod 2) 이고, 블록 b 는 자기 아래 s_b 개의
j_i 각각에 대해 한 번씩 세어지므로  D ≡ Σ_b s_b φ_b ≡ Σ_{s_b 홀수} φ_b (mod 2).
따라서 2D ≡ 2 Σ_{s_b 홀수} φ_b (mod 4).                          [QED]

## 따름정리 (global)

빈 보드 -> 퍼펙트 클리어이므로 Σ Δφ = 0. T 만 ±2 를 기여하므로

    Σ_clears Δφ_clear  ≡  2 · #T   (mod 4)

그리고 Σ_clears A 는 항상 짝수. 2로 나누면 사람이 읽는 형태:

    #T  ≡  Σ_clears D  +  (Σ_clears A)/2    (mod 2)

w 짝수면 A = 0 이므로

    #T  ≡  Σ_clears (지워진 줄 위에 남은 칸 수)    (mod 2)

클리어가 없거나 모두 짝수 칸을 위에 남기면 우변 0 -> #T 짝수.
**원래 MSE 가설은 이 정리의 특수한 경우다.**

## 폐기된 중간 형태 (기록용)

초기에 세웠던 corr = Δφ/2 는 w 홀수에서 깨진다. 꽉 찬 줄이 w 칸(홀수)이라
Δφ 가 홀수일 수 있어 정수가 아님. w=5 에서 48568 건의 "불일치"가 나왔는데
전부 이 정의 오류였고 반례가 아니었다. mod 4 로 올려서 해결.

또 A 를 폭과 무관하게 Σ(-1)^(j_i) 로 두면 짝수 폭에서 틀린다.
꽉 찬 줄의 φ 기여는 (-1)^j · Σ_c (-1)^c 이고 짝수 폭에서 후자가 0.
